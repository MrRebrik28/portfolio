## ⚡ Особенности архитектуры самого сайта-портфолио

- **Fluid Custom Cursor:** Плавный двухкомпонентный курсор с физикой преследования (Lerp), магнитным притяжением и состоянием `СМОТРЕТЬ` при наведении на кейсы.
- **Interactive Background Canvas:** Живая сеть частиц и неоновой сетки с отталкиванием от курсора мыши и энергосберегающим pause-режимом.
- **Sound Effects (Web Audio API):** Встроенный синтезатор микро-щелчков и тактильных звуков при наведении и открытии модалок (чистый процедурный звук без внешних MP3-файлов, с кнопкой `SFX ON / OFF`).
- **3D Card Perspective Tilt:** Динамический наклон карточек в реальном времени с расчетом координат мыши и световым бликом.
- **Native Accessible `<dialog>` Modal:** Реализован по стандартам *Modern Web Guidance* (`overscroll-behavior: contain;`, стилизованный `::backdrop`, плавная анимация входа/выхода, закрытие по `Esc` и клику вне окна, прямые ссылки на кейсы `#case-id`).
- **Интерактивный калькулятор сметы:** Динамический расчет ориентировочной стоимости и сроков проекта с авто-генерацией готового брифа в Telegram.
- **Live Local Time:** Живые часы с часовым поясом Сибири/Кузбасса (UTC+7).
- **One-Click Email Copy:** Быстрое копирование контактов с анимированным всплывающим toast-уведомлением.

## 🚀 Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/MrRebrik28/portfolio.git
cd portfolio

# Быстрый запуск статического сервера
python -m http.server 8080
# или через Node
npx serve .
```
Откройте в браузере: `http://localhost:8080` (или `http://localhost:3000`).
