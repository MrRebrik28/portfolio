## 1. Фундамент: Философия светлых интерфейсов (Light-First)

Для всех создаваемых коммерческих, корпоративных и продуктовых сайтов базовой и приоритетной является **светлая тема (Light Theme)**.

### Почему светлый дизайн — промышленный стандарт:
1. **Высокая читаемость и меньшая усталость глаз:** В светлое время суток и при естественном освещении светлый фон обеспечивает более быструю скорость считывания текста (доказано исследованиями зрительного восприятия).
2. **Психологическое доверие:** Светлые чистые поверхности подсознательно ассоциируются с открытостью, легитимностью, стерильностью и надежностью бизнеса (B2B, медицина, e-commerce, финтех, образование).
3. **Универсальность для интеграций:** Любые скриншоты документов, товарные фото на белом фоне и инфографика органично смотрятся на светлой подложке без грязных артефактов обтравки.

### Иерархия светлых поверхностей (Surface Hierarchy):
```css
:root {
  /* Базовый холст */
  --surface-canvas:      #F8FAFC; /* Чистый холодный/нейтральный светло-серый фон страницы */
  --surface-card:        #FFFFFF; /* Белоснежные карточки первого плана */
  --surface-elevated:    #FFFFFF; /* Выпадающие списки, модальные окна, тултипы */
  --surface-muted:       #F1F5F9; /* Вторичные секции («зебра»), табы, заливки тегов */
  --surface-subtle:      #E2E8F0; /* Разделители, линии сетки, неактивные границы */

  /* Контрастный текст (WCAG AAA) */
  --text-main:           #0F172A; /* Глубокий темно-сланцевый (НЕ чистый #000, чтобы не резать глаз) */
  --text-muted:          #475569; /* Вторичный текст, параграфы, описания */
  --text-caption:        #64748B; /* Метаданные, плейсхолдеры, даты, мелкие подписи */
  --text-on-accent:      #FFFFFF; /* Белый текст поверх акцентных кнопок */

  /* Микро-тени (Soft Ambient Shadows вместо жирных рамок) */
  --shadow-sm:           0 1px 2px 0 rgba(0, 0, 0, 0.05);
  --shadow-card:         0 4px 6px -1px rgba(0, 0, 0, 0.05), 0 2px 4px -2px rgba(0, 0, 0, 0.05);
  --shadow-hover:        0 12px 24px -4px rgba(0, 0, 0, 0.08), 0 4px 6px -2px rgba(0, 0, 0, 0.04);
  --shadow-modal:        0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 8px 10px -6px rgba(0, 0, 0, 0.1);
}
```

## 2. Психология цвета и подбор палитры по направлениям

Цветовая гамма сайта **никогда не выбирается наугад или по личному вкусу дизайнера**. Цвет — это психологический триггер доверия, конверсии и позиционирования бренда.

### Правило 60–30–10 в светлых интерфейсах:
- **60% — Доминирующий фон:** Белый и нейтральный светло-серый (`--surface-canvas`, `--surface-card`). Обеспечивает воздух, свет и чистоту.
- **30% — Вторичный структурирующий цвет:** Тёмный текст (`--text-main`), тонкие контуры блоков, карточки на сером фоне, фотоконтент. Создает каркас и читаемость.
- **10% — Единственный акцентный цвет (Call-to-Action):** Главные кнопки конверсии, активные фильтры, статус «В наличии», бейджи и ссылки. Акцент должен мгновенно направлять взгляд.

## 3. Типографическая система из архива шрифтов (35 шрифтов)

В архиве `35_бесплатных_шрифтов.zip` собраны профессиональные гарнитуры с поддержкой кириллицы.  
**Железное правило:** в одном проекте используется **максимум 2 шрифта** (Заголовок + Текст) или 1 развитая супергарнитура.

### Матрица связок шрифтов под задачи сайта:

#### Вариант 1. Универсальный современный IT / SaaS / E-commerce (Рекомендуемый стандарт)
- **Заголовки (H1–H3):** `Montserrat` (`wght@700` или `800`) — уверенная геометрия, чистые пропорции.
- **Основной текст и списки:** `Open Sans` или `Roboto` (`wght@400`, `500`) — максимальная разборчивость при быстром чтении.
- **Код / Метрики / Цены:** `IBM Plex Mono` или `Roboto Mono`.

#### Вариант 2. Высокие технологии, Авто, Спорт, Гейминг, Кибер-стартап
- **Заголовки:** `Exo 2` (`wght@700` или `800`) — футуристичные динамичные скосы и технологичный характер.
- **Основной текст:** `PT Sans` или `Lato` (`wght@400`, `500`) — нейтральный читаемый гротеск.

#### Вариант 3. Премиальный сервис, Рестораны, Мода, Бьюти, Недвижимость
- **Заголовки:** `Playfair Display` (`wght@700`, `Italic`) — изысканная высококонтрастная антиква, создающая ощущение обложки журнала Vogue.
- **Основной текст:** `Montserrat` (`wght@300`, `400`) или `Source Sans Pro`.

#### Вариант 4. Корпоративный портал, Промышленность, B2B, Инженерия
- **Заголовки:** `IBM Plex Sans` (`wght@600`, `700`) или `Roboto Slab` — монолитный, устойчивый, авторитетный.
- **Основной текст:** `IBM Plex Sans` (`wght@400`) или `PT Sans`.

#### Вариант 5. Медиа, Лонгриды, Экспертные блоги, Аналитика
- **Заголовки:** `Merriweather` (`wght@700`, `900`) — классическая журнальная антиква.
- **Основной текст:** `Source Sans Pro` (`wght@400`, `line-height: 1.7`) — оптимальный межстрочный интервал для чтения длинных статей.

#### Вариант 6. Тяжелая индустрия, Стройка, Спецтехника, Энергетика
- **Заголовки:** `Russo One` (All-Caps, монолитная плотность) или `Kelly Slab`.
- **Основной текст:** `Roboto` (`wght@400`, `500`).

## 4. Принципы UX-дизайна (Удобство, Логика и Архитектура)

Каждое интерфейсное решение обязано следовать 8 законам проектирования пользовательского опыта:

### 1. Фокус на пользователе (User-Centered Design)
- Продукт создается под реальные задачи, боли и привычки целевой аудитории, а не под вкус дизайнера или заказчика.
- Любое решение проверяется вопросом: *«Поможет ли это посетителю быстрее решить его проблему?»*.

### 2. Правило KISS (Keep It Simple, Stupid)
- Интерфейс должен быть максимально простым, без лишних промежуточных шагов, дублирующих полей и визуального нагромождения.
- Чем меньше элементов на странице, тем меньше когнитивная нагрузка на мозг посетителя.

### 3. Закон Миллера (7 ± 2 смысловых блока)
- Кратковременная память человека способна одновременно удерживать **5–9 смысловых единиц**.
- Главная навигация сайта должна содержать **от 4 до 7 пунктов** (не перегружать шапку 12 ссылками).
- Длинные списки, тарифы и каталоги обязательно разбиваются на логические группы по 3–5 элементов с подзаголовками.

### 4. Закон Фиттса (Размер и доступность кнопок)
- Время достижения цели зависит от **расстояния до объекта и его физического размера**:
  - На мобильных устройствах минимальный размер кликабельной области кнопки — **48×48 px** (зона пальца).
  - Главные целевые кнопки (CTA: «Оформить заказ», «Купить») размещаются внизу экрана в зоне досягаемости большого пальца (Thumb Zone).

### 5. Правило минимума усилий (Правило 2–3 кликов)
- От первого входа на сайт до целевого действия (покупка, отправка заявки, звонок) пользователь должен доходить максимум за **2–3 простых действия**.
- Формы заявок должны содержать только критически важные поля (Имя + Телефон/Telegram). Каждое лишнее поле снижает конверсию на 15–20%.

### 6. Обратная связь (Immediate Feedback)
- Система обязана реагировать на каждое действие пользователя:
  - Наведение на кнопку (Hover) — плавное изменение тона и микро-подъем.
  - Нажатие (Active) — визуальный клик.
  - Загрузка данных — появление скелетона (Skeleton Loading) или спиннера.
  - Успех операции — зелёный toast-нотис («Заявка отправлена», «Скопировано в буфер»).

### 7. Защита от ошибок (Error Prevention & Recovery)
- Необратимые и критические действия (удаление проекта, списание средств, очистка корзины) **всегда** сопровождаются модальным окном подтверждения: *«Вы уверены, что хотите удалить элемент? Это действие нельзя отменить»*.
- Поля ввода должны иметь «живую» валидацию: маска телефона (`+7 (___) ___-__-__`), проверка корректности email до нажатия кнопки «Отправить».

### 8. Консистентность (Consistency)
- Одинаковые сущности на всех страницах и модальных окнах выглядят и функционируют одинаково:
  - Крестик закрытия окна всегда в правом верхнем углу.
  - Первичная кнопка всегда имеет акцентный цвет и находится справа от кнопки «Отмена».
  - Иконки берутся строго из одного сета с одинаковой толщиной обводки (например, 2px).

## 5. Принципы UI-дизайна (Визуальная гармония и верстка)

### 1. Визуальная иерархия (Visual Hierarchy)
- Главное на экране считывается за первые **3 секунды**:
  1. Крупный заголовок H1 (УТП продукта).
  2. Подзаголовок (раскрытие ценности).
  3. Кнопка призыва к действию (CTA).
- Если на экране одновременно выделено всё (3 яркие кнопки, цветной фон, бегущие строки) — значит, не выделено ничего.

### 2. Законы Гештальта (Близость, замкнутость и подобие)
- **Закон близости (Правило внутреннего и внешнего):**  
  Отступ внутри блока между заголовком и его параграфом всегда **меньше**, чем расстояние от этого блока до следующего соседнего элемента.
- **Закон замкнутости:** Связанная информация (карточка товара: фото + цена + название + кнопка) заключается в единую карточку с белой подложкой и мягкой границей.

### 3. Контрастность и доступность (Accessibility WCAG AA/AAA)
- Контраст между цветом текста и фоном должен составлять:
  - Минимум **4.5:1** для обычного текста.
  - Минимум **3:1** для крупных заголовков.
- Запрещено использовать светло-серый текст на белом фоне (частая ошибка некачественных дизайнеров).

### 4. Паттерны сканирования взгляда (Eye-Tracking Patterns)
- **F-паттерн (для контентных и текстовых страниц):** Пользователь сканирует верхнюю строку, затем спускается вниз по левому краю, цепляясь за подзаголовки и маркеры списков.
- **Z-паттерн (для посадочных лендингов):** Логотип (слева вверху) → Меню/Контакты (справа вверху) → Главный заголовок с фото (центр по диагонали) → Кнопка CTA (справа внизу первого экрана).
- **Вертикальный мобильный ритм:** Одноколоночная верстка без горизонтальной прокрутки, ключевая информация размещается по центру строки.

### 5. Использование дизайн-систем и UI Kit
- Любой сайт строится из библиотеки переиспользуемых мастер-компонентов в Figma и CSS:
  - Базовые типографические стили (H1, H2, H3, Body-L, Body-M, Caption).
  - Сетка отступов (кратная 4px или 8px: `8, 16, 24, 32, 48, 64, 96px`).
  - Состояния кнопок: `Primary`, `Secondary`, `Ghost`, `Danger`, `Disabled`.
  - Модальные окна, дропдауны, аккордеоны FAQ.

## 6. Чек-лист проверки качества светлого сайта перед сдачей

- [ ] **Тема:** Дизайн выполнен на чистом светлом фоне (`#F8FAFC` / `#FFFFFF`)? Нет грязных серых пятен?
- [ ] **Психология цвета:** Акцентный цвет выбран строго под сферу бизнеса (синий — финтех, бирюзовый — медицина, зеленый — эко, оранжевый — e-commerce)?
- [ ] **Пропорция цвета:** Соблюдено ли правило 60–30–10? Акцентный цвет не забивает весь экран?
- [ ] **Шрифты:** Использовано максимум 2 шрифта из согласованного списка (например, `Montserrat` + `Open Sans`)?
- [ ] **Закон Миллера:** В главном меню не более 7 пунктов?
- [ ] **Закон Фиттса:** Кнопки крупнее 44px, отступы между ссылками достаточные для пальца?
- [ ] **Правило 2–3 кликов:** Пользователь может оставить заявку или заказать товар за 2–3 простых действия?
- [ ] **Обратная связь:** Все интерактивные элементы реагируют на hover/click? При отправке формы появляется подтверждение?
- [ ] **Защита от ошибок:** Для необратимых действий предусмотрено окно подтверждения?
- [ ] **Контрастность:** Текст имеет контраст не менее 4.5:1 к фону и легко читается при ярком солнце?
