# Агент автоматического озвучивания экскурсий «ПешКем»

Специализированный агент для пакетной генерации аудиогида по всем 26 историческим точкам города Кемерово через платформу **FreeTTS.ru** с использованием голоса **Никиты Калинина** (`rus_Nikita_Kalinin`).

## 2. Возможности агента

1. **Автоматический сбор контента**:
   - Агент считывает все 26 остановок 3 маршрутов из `scripts/peshkem-data.js` с приоритетом адаптированных текстов экскурсовода (`audioText`).
2. **Фонетическая нормализация текста**:
   - Раскрывает сокращения («ул.» -> «улица», «г.» -> «года», «тыс.» -> «тысяч», «км» -> «километров», «им.» -> «имени», «АИК» -> «А-И-К») для естественного и связного звучания.
3. **Пакетная генерация MP3**:
   - Выполняет защищенные WebSocket-запросы по стандарту RFC 6455 к `wss://api.freetts.ru/generate`.
   - Сохраняет аудиофайлы в `assets/peshkem/audio/{stopId}.mp3`.
4. **Интеграция с плеером сайта**:
   - Аудиоплеер сайта `scripts/peshkem-audio.js` автоматически подхватывает созданные MP3-файлы и воспроизводит живую дикторскую дорожку, а при сетевых задержках бесшовно активирует голосовой синтез браузера.

## 3. Инструкция по запуску

Запуск из терминала в корне проекта:

### Посмотреть список всех доступных голосов FreeTTS:
```bash
python tools/peshkem_audio_agent.py --list-voices
```

### Тестовый запуск без отправки запросов (Dry Run):
Агент проверит все 26 текстов, покажет нормализованный дикторский текст, число слов и хронометраж:
```bash
python tools/peshkem_audio_agent.py --dry-run
```

### Озвучить одну конкретную остановку (голосом Никиты Калинина):
```bash
python tools/peshkem_audio_agent.py --stop stop-1-circus --voice rus_Nikita_Kalinin
```

### Запустить полную переозвучку всех 26 точек маршрутов:
```bash
python tools/peshkem_audio_agent.py --all --voice rus_Nikita_Kalinin
```
