# Агент автоматического озвучивания экскурсий «ПешКем»

Специализированный агент для пакетной генерации аудиогида по всем 26 историческим точкам города Кемерово через платформу **FreeTTS.ru** и нейросетевые TTS-движки.

## 2. Возможности агента

1. **Автоматический сбор контента**:
   - Агент сам считывает все 26 остановок 3 маршрутов из файла `scripts/peshkem-data.js`.
2. **Фонетическая нормализация текста**:
   - Раскрывает сокращения («ул.» -> «улица», «г.» -> «года», «тыс.» -> «тысяч», «км» -> «километров», «им.» -> «имени») для естественного и связного звучания.
   - Добавляет вступительный анонс точки (например: *«Остановка. Старый цирк...»*).
3. **Пакетная генерация MP3**:
   - Автоматически обращается к API / WebSocket `wss://api.freetts.ru/generate`.
   - Сохраняет аудиофайлы с понятными именами в папку `assets/peshkem/audio/{stopId}.mp3`.
4. **Интеграция с плеером сайта**:
   - Аудиоплеер сайта `scripts/peshkem-audio.js` автоматически подхватывает созданные MP3-файлы и воспроизводит живую дикторскую дорожку вместо синтетического голоса браузера.

## 3. Инструкция по запуску

Запуск из терминала в корне проекта:

### Посмотреть список всех доступных голосов FreeTTS:
```bash
python tools/peshkem_audio_agent.py --list-voices
```

### Тестовый запуск без отправки запросов (Dry Run):
Агент проверит все 26 текстов, покажет нормализованный дикторский текст, число слов и хронометраж:
```bash
python tools/peshkem_audio_agent.py --dry-run
```

### Озвучить одну конкретную остановку (например, Старый цирк):
```bash
python tools/peshkem_audio_agent.py --stop stop-1-circus --voice rus_Leonid_Vorobev
```

### Запустить полную озвучку всех 26 точек маршрутов:
```bash
python tools/peshkem_audio_agent.py --all --voice rus_Leonid_Vorobev
```
